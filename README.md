The World — Saturday 21 November 2026: a broadsheet front page summing up the day's world news in one image, drawn with Pillow. Lead story: war in the Strait of Hormuz. Also: missiles land in Poland, UN "killer robot" rules off to 2028, COP31 talks run past deadline, Brussels proposes a Big Tech tax, India 486/4 lead 118, and Bangladesh marks Armed Forces Day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB). The program uses only the standard library plus Pillow, and only Pillow's bundled font, so it runs the same in any container that has Pillow.
